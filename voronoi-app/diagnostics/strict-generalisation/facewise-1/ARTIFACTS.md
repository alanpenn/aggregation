# Corrected strict axial experiment on GitHub

This snapshot contains the corrected Hill and Converging Valleys cases for seeds 40–45, including the report, statistical tables, case journals, saved full-pool route references, visual indexes, and vector maps. The axial atlas covers all 60 method maps, with comparison sheets, corridor changes, and growth audits. The legacy pilot summaries and exact selected intervals are in the sibling `pilot-1` directory.

The local experiment archive also contains individual high-resolution PNGs, immutable batch record directories, and source snapshots. The visual indexes and export record describe the complete experiment, so PNG paths and raw batch lineage IDs refer to assets in that archive. The vector PDF paths in the corrected visual indexes are available in this checkout. The export record covers the original exported artifacts and gives SHA-256 hashes for verification.

To resume from existing batch records or regenerate using the archived inputs, restore the complete diagnostics archive alongside this checkout. The [scientific report](report.md) documents the rerun commands and validation methods.
